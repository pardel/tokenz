# Tokenz app icon

Created with the built-in image generation tool. The source artwork is `AppIcon.png`; `AppIcon.icns` contains the native macOS sizes from 16px through 1024px, including Retina representations. Rebuild with `./scripts/build-icon.sh` or the normal app build script.

Selected variant: **6, Token Ledger**, from the ten icon candidates. Three stacked token slabs sit on a charcoal tile. The ivory top slab carries an inset T, and the amber and blue layers match the app's provider accents. Transparency surrounds the sculpted tile.

## Final generation prompt

Recorded verbatim, so it keeps the working name the app had when the icon was generated.

Use case: stylized-concept. Create ONE final production macOS application icon for Tonkenz, a menu bar app tracking token usage and subscription consumption across Claude Code and Codex. Square high-resolution image. Front-facing orthographic icon, centered native macOS squircle tile with about 7% transparent outer margin. One cohesive dominant emblem, distinctive and highly readable at 32px. Carefully composed premium icon art, crisp boundaries and generous negative space. Actual alpha transparency outside the tile; no backdrop scene or baked checkerboard. No mockup, no extra frame, no decorative sparkles, no neon haze, no invented provider logos, no watermarks, no percentages, no labels, no numbering. Only depict any letter specifically requested in the concept. Concept: A soft charcoal squircle containing a striking stack of three broad token-chip slabs with rounded corners, staggered upward like usage accumulation. The top slab is ivory with a deeply inset geometric T; the edges of the lower two slabs are bold amber and azure. Front-on mostly orthographic composition, subtle depth from the layering only, refined physical sculpture, large clear shapes.
